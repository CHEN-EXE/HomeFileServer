# HomeFileServer
一个面向ESP硬件平台的家庭文件共享web网页python程序，通过连接网络共享文件并支持下载和删除。
## 使用注意
启动项目前请将`config.txt`里面的`WIFI`和`WIFIPWD`修改为家中 WIFI名称 和 WIFI密码！<br>
启动后访问终端返回的设备IP即可进入设置页，配置个性化信息后进入文件管理器
> [!WARNING]
> 由于单片机本身存储容量小，项目仅支持上传小文件/图片。
